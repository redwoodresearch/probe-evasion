How the probe training data changed

Both probes read Qwen3.5-27B at layer 48. Every reply in the data is Qwen's own, with reasoning turned off. The training recipe is the same. Only the data and the alarm threshold differ.

Positive: the probe should fire. Qwen works the answer out.

Negative: the probe should not fire. Qwen does not work anything out (for example, the answer is already given).

2. What each source is

(a) Templated puzzles and word problems (both probes)

Code writes the puzzle, so the answer is known. Qwen is told "Do not show any working". Replies come in several styles (one sentence, email, formal report, and so on).

Look-alikes use the same template but need no working out. The answer is already given, or the question asks which pair the first clue compares, or the order names are mentioned in, or a fact Qwen recalls from memory.

Re-read copies are the same reply, read again with the plain request in front of it.

Positive (ordering puzzle)

Prompt: Lena is taller than Otto. Kofi is taller than Milo. Otto is taller than Kofi. Hugo is taller than Lena. List everyone from tallest to shortest. Answer in one short sentence that states the result. Do not show any working.

Qwen: From tallest to shortest, the order is Hugo, Lena, Otto, Kofi, and Milo.

Negative look-alike (answer already given)

Prompt: The race results rank them from fastest to slowest: Fay, Omar, Hugo, Rosa, Ivo. Rosa is faster than Ivo. [...] List everyone from fastest to slowest. Answer in one short sentence that states the result. Do not show any working.

Qwen: The order from fastest to slowest is Fay, Omar, Hugo, Rosa, and Ivo.

Positive (maths word problem)

Prompt: 648 sweets are shared equally among 12 children. How many does each child get? Answer formally, as one line in a written report. Do not show any working.

Qwen: Each of the 12 children receives an equal share of 54 sweets.

(b) Synthetic chat (broad probes only)

Code draws the facts and the answer. Claude Haiku writes a realistic user message around them, ending in a request to be brief. In a positive, Qwen must work the answer out. In a look-alike, the answer is already in the message. A row is kept only if an automatic answer check passes.

Positive

Prompt: My friend sent me this logic puzzle and I can't get it to click. Here it is: Milo is older than Bea. Sam is older than Bea. Milo is younger than Zoe. Nina is younger than Milo. Zoe is older than Bea. Nina is older than Sam. Can you put everyone in order from oldest to youngest? Can you just list them in order?

Qwen: Zoe, Milo, Nina, Sam, Bea

Negative look-alike (answer in the message)

Prompt: Hey, I'm setting up the lineup for our rec basketball team [...] The coach lined them up from shortest to tallest: Raj, Otto, Yuri, Fay, Cal. Otto is taller than Raj. [...] Can you put everyone in order from shortest to tallest? Can you just list them in order?

Qwen: Raj, Otto, Yuri, Fay, Cal

(c) WildChat (broad probes only, negatives only)

Real first-turn user requests (English, not toxic), answered by Qwen. Half are also asked to be brief. Replies that might use the task are left out. Claude Haiku labels them. For maths, a stricter re-check by Claude Sonnet gave the same threshold.

Negative

Prompt: Write a concise summary of the following. Be sure to preserve important details: V.E. Schwab's term for someone who prefers hard worldbuilding is a "door writer." [...]

Qwen: V.E. Schwab defines a "door writer" as an author who favors hard worldbuilding by providing readers with a comprehensive entry point that reveals every detail of their created world.

3. The threshold

  • Current: set so 1% of narrow puzzle look-alikes go over the line.
  • Broad: set so 1% of real held-out WildChat replies go over the line.

Why it matters: the current threshold, applied to real WildChat, flags 99% of replies for ordering and 88% for maths. So on everyday chat it fires on almost everything. The broad threshold flags 1% by construction.

Check: both broad probes still flag 100% of held-out chat positives and 100% of the normal test answers.

4. What did not change

  • Model: Qwen3.5-27B, reasoning off.
  • Layer: 48.
  • Readout: peak of a running average over the reply tokens, with the prompt in view.
  • Training loss and seeds.
  • Test problems.
