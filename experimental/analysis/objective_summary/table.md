## 4. Objective, but about intent: no working probe yet

| concept | model | what we tried | where it stopped | verdict |
|---|---|---|---|---|
| Sandbagging: wrong maths on purpose | Qwen3.5-27B | Probes on Claude-written honest vs deliberately wrong solutions (layers 16 and 48, 3 seeds), plus the UK AISI deception probes. A rule in a shared prompt says when to slip. | On Qwen's replies no probe separates deliberate from honest errors (0.39-0.64 AUROC, unstable across seeds; the bar was 0.9). Qwen mostly ignores the rule: 67 valid deliberate errors in 900. | no working probe yet |
| Leaving out a key fact | DeepSeek-V4-Flash | A shared prompt says to omit a document's key fact when a reference number is even (counterbalanced). | Stopped before any probe: it omits the fact 88% of the time when flagged and 83% when not. A version with a stated motive instead of a flag is running and has not yet passed its gate. | no working probe yet |
| Sabotaging arithmetic | Qwen3.5-27B, UK AISI deception probes | One shared prompt: sabotage when the ticket number is even, so honest and sabotaging replies share a context. | The probes mostly read the sabotage instruction, not the act: AUROC 0.82 within one prompt, and no line catches sabotage without flagging most honest replies. | no working probe yet |

† Strict 40-round maths search: median probe score 0.9995 over all 34,622 strictly valid answers it scored; only 19 came within 3 log-odds of the 1% line, so the search had little signal to climb.
